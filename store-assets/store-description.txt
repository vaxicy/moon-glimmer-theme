Moon Glimmer Theme softens the browser into a quiet lilac key. A pale lavender frame and tab strip sit above a slightly deeper lilac toolbar, while deep violet text keeps every label readable on its own layer. Links, the active tab mark and the store artwork all share a single midnight indigo accent. Each surface is a flat, single solid color, so the browser stays calm and uncluttered. The palette lives entirely in the theme definition, so installing it simply recolors the browser.
